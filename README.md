# TypeMend

System-wide, sentence-aware autocorrect, grammar hints and current-word completion for macOS, powered by your Codex login (GPT-6 Luna).

**Download:** grab the latest `.dmg` from [Releases](https://github.com/MrBiscuit/typemend-releases/releases/latest), drag TypeMend to Applications, open it, and drag it into the Accessibility list when System Settings appears.

Requires macOS 14+ and the ChatGPT app or the `codex` CLI signed in. Signed with Developer ID and notarized by Apple.
